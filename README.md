A plan for an AI agent to turn $100, a computer and 30 days into the most money: done-for-you Google Business and review pages for local trades, sample-first at $49 prepaid, with honest day-30 math and a kill rule for any channel that does not pay.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the plan to `out/entry.txt` — 995 characters, inside the gate's 1 to 1,000.
